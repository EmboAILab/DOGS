Abstract

Object-level 3D scene reconstruction requires representations that preserve appearance while exposing foreground objects and background context as separately manageable components. Conventional scene-level 3D Gaussian Splatting couples these components in one parameter field, obscuring object ownership and complicating object removal, background recovery, and scene recomposition.

DOGS addresses this representation gap through one multi-object optimization that maintains an instance-identity distribution for each Gaussian. Cross-view instance masks, foreground supervision, and mask-outside alpha suppression establish object-aware parameter groups, which are extracted by hard identity assignment after convergence. A separately supervised background Gaussian model combines visible-background observations with weak inpainting priors, and parameter-level scene composition assembles the resulting components in a shared coordinate system.

The current evidence follows traceable real-scene and real-to-virtual records: object relocation, background recovery after object removal, four-category correspondence across real and virtual views, and selected USDZ visual-import records in Isaac Sim. These observations support a visual scene-representation and asset-provisioning interpretation; they do not establish URDF or Isaac Lab compatibility, hierarchy validation, collision-proxy loading, numerical scale accuracy, dynamics accuracy, or closed-loop task performance.

Key Contributions

Object-level Gaussian assets

DOGS moves explicit 3D Gaussian representation from coupled scene reconstruction toward object-level structured assets that can be independently managed, reused, and recomposed.

Foreground and alpha decoupling

Instance-mask foreground supervision and mask-outside alpha suppression restrict each identity-aware object group to its own support region and reduce non-target opacity responses.

Asset-interface composition

Independent object and background Gaussian models are composed in a shared coordinate system, supporting omission, repositioning, visual recomposition, and downstream USD/USDZ conversion.

Method

1

Object Gaussian Subspaces

A single multi-object optimization maintains an instance-identity distribution for every Gaussian. After convergence, confidence-thresholded hard assignment exports each object Gaussian subspace without retraining.

L_object = mean_masked(L1 RGB) + lambda_alpha * mean_outside(|alpha|)
2

Background Gaussian Model

The background is trained after object regions are excluded. Visible and LaMa-inpainted regions are normalized separately, the inpainted term is weighted by rho, and local plane residuals regularize background Gaussian centers.

L_bg = L_bg-rgb + lambda_reg * L_bg-reg, rho = 0.1
3

Parameter-level Scene Composition

Objects and background are directly merged in the shared world coordinate system and rendered using the standard Gaussian Splatting renderer.

G_scene = G_bg union {G_obj}

Code And Assets

The source release provides the paper-aligned training losses, PSNR/SSIM/LPIPS evaluation, the reported leakage metric, an auxiliary boundary-analysis protocol, executable parameter-level composition, conversion utilities, simulation-interface documentation, figure-level provenance, and a category-level asset policy.

Source-resolution media, original recordings, model weights, Gaussian outputs, and USD/USDZ assets are not included in this public release. The public manifests document only category-level local paths and do not provide or advertise a data-download package.
