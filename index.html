DOGS: Decoupled Object Gaussian Splatting for Interactive Robot Simulation

Object-level 3D Gaussian scene representation for reusable robot-simulation and digital-twin assets

Qu Yuanjin Hu Xiangtao Yin Fanghao Miao Lixuan Ji Xiang
EmboAI Lab
Code Assets Citation

DOGS decomposes a multi-view scene into independent object Gaussian subspaces and a background Gaussian model, then directly recomposes them in a shared world coordinate system for robot simulation.

Abstract

Digital-twin scenes for embodied AI and robot simulation require physical objects to be reconstructed with high visual fidelity and organized as independently manageable, reusable, and composable 3D assets. Existing 3D Gaussian Splatting methods usually optimize the whole scene as a single coupled Gaussian field, which limits object-level controllability and asset-oriented deployment.

We propose DOGS, a Decoupled Object Gaussian Splatting framework for robot simulation. DOGS uses cross-view consistent instance masks to optimize each object in an independent Gaussian subspace. Object models receive foreground supervision only inside their target masks, while mask-outside alpha suppression discourages non-target opacity responses, reducing boundary bleeding, background leakage, and cross-object interference. The background is modeled separately with object regions removed, completed appearance priors, and local geometry regularization for occluded regions. Because all subspaces share the same world coordinate system, object and background models can be merged at the parameter level without additional joint optimization or post-hoc alignment.

Experiments on real and public multi-view datasets show that DOGS preserves scene-level rendering quality while improving object separation purity, background continuity, and composed-scene consistency. This makes DOGS suitable for object asset construction, scene reorganization, and digital-twin deployment in robot simulation.

Key Contributions

Object-level Gaussian assets

DOGS moves explicit 3D Gaussian representation from coupled scene reconstruction toward object-level structured assets that can be independently managed, reused, and recomposed.

Foreground and alpha decoupling

Instance-mask foreground supervision and mask-outside alpha suppression restrict each object model to its own support region and reduce non-target opacity responses.

Simulation-ready composition

Independent object and background Gaussian models are directly composed in a unified coordinate system, supporting scene reorganization, object replacement, and robot-simulation deployment.

Method

1

Object Gaussian Subspaces

Each target instance is optimized as an independent object Gaussian model using multi-view RGB images and cross-view consistent instance masks.

L_object = L_obj-fg + lambda_alpha L_obj-alpha
2

Background Gaussian Model

The background is trained after object regions are excluded, with LaMa-based completion priors and local geometry regularization for long-term occluded regions.

L_bg = L_bg-rgb + lambda_reg L_bg-reg
3

Parameter-level Scene Composition

Objects and background are directly merged in the shared world coordinate system and rendered using the standard Gaussian Splatting renderer.

G_scene = G_bg union G_obj
