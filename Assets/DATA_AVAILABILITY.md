# Data Availability

## Public Benchmark Data

Mip-NeRF360, LLFF, and LERF-Mask are public datasets and are not mirrored in
this repository. They should be obtained from the original project
repositories cited in the manuscript.

## Selected Self-Collected RGB Data

A curated package is maintained outside the Git repository for research
access through the corresponding author. It contains 404 JPEG images in six
groups:

- one 112-view multi-object scene;
- one 55-view aluminum-case reference capture;
- one 51-view white-cabinet reference capture;
- one 26-view metal-bowl reference capture;
- one 26-view orange-handle reference capture;
- 134 empty-background views.

The released JPEG coefficients are copied losslessly with APP/COM metadata
removed. Capture timestamps, camera-body and lens serial numbers, GPS fields,
author fields, and local paths are absent. A sidecar table retains only
non-identifying image dimensions and photographic parameters, and a SHA-256
manifest covers every released file.

The package contains source RGB captures. Masks, camera poses, and train/test
products are generated by the preprocessing protocol described in the
manuscript and code release. Derived renders, checkpoints, Gaussian PLY files,
USD/USDZ assets, and simulator outputs are not included in the data package.
