# Data Availability

## Public Benchmark Data

Most benchmark experiments reported in the manuscript use public data. These
datasets are not mirrored in this repository and should be obtained from their
original project pages:

- [Mip-NeRF360](https://jonbarron.info/mipnerf360/)
- [LLFF](https://github.com/Fyusion/LLFF)
- [LERF-Mask](https://github.com/lkeab/gaussian-grouping/blob/main/docs/dataset.md)

## Selected Partial Self-Collected Data

A metadata-sanitized package is published in the
[DOGS data-v1.0.0 release](https://github.com/EmboAILab/DOGS/releases/tag/data-v1.0.0).
It contains 627 RGB images in nine groups:

| Release folder | Images | Content |
| --- | ---: | --- |
| `multi_object_scene` | 112 | Shared real scene containing four foreground objects |
| `object_reference_aluminum_case` | 55 | Aluminum-case reference capture |
| `object_reference_white_cabinet` | 51 | White-cabinet reference capture |
| `object_reference_metal_bowl` | 26 | Metal-bowl reference capture |
| `object_reference_orange_handle` | 26 | Orange-handle reference capture |
| `empty_background_views` | 134 | Object-free desk background views |
| `composed_scene_sequence` | 113 | Real composed-scene sequence from `combination` |
| `metal_bowl_sequence` | 55 | Additional object sequence from `guo` |
| `kettle_sequence` | 55 | Additional object sequence from `hu` |

This is a selected partial release, not the complete evaluation corpus. JPEG
coefficients are copied losslessly with APP/COM metadata removed, and PNG files
are losslessly re-encoded without ancillary metadata. Capture timestamps,
camera-body and lens serial numbers, GPS fields, author fields, and local paths
are absent. `IMAGE_METADATA.csv` retains only non-identifying dimensions and
photographic parameters. `FILE_MANIFEST_SHA256.csv` records the byte size and
SHA-256 digest of every released image.

The package contains source RGB captures only. Masks, camera poses, and
train/test products are generated by the preprocessing protocol described in
the manuscript and code release. Derived renders, checkpoints, Gaussian PLY
files, USD/USDZ assets, and simulator outputs are not included.
